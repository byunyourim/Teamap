# Teamap 레이아웃 설계

## 컨셉트
팀 업무 관리 + 운영 플랫폼. 슬랙 스타일 Electron 데스크탑 앱.

## 레이아웃

3-컬럼 구조:

```
┌──────┬─────────────┬──────────────────────────┐
│카테고│  서브 메뉴    │      메인 컨텐츠           │
│리 바 │             │                          │
│      │             │  (선택된 항목의 상세 내용)   │
│ 개인 │             │                          │
│ 운영 │             │                          │
└──────┴─────────────┴──────────────────────────┘
 44px     220px              나머지
```

## 대메뉴

| 카테고리 | 설명 |
|---|---|
| 개인 | 업무 목록, 작업 진행 상황, 파트 내 업무 현황 |
| 운영 | 에러 로그 분석, 서비스 재기동, 버그 지점 파악 |

## 개인 탭 하위 메뉴

- **내 업무** — 나에게 할당된 작업 목록 + 진행 상태
- **파트 업무** — 내가 속한 파트의 전체 업무 현황
- **팀원 현황** — 파트 내 팀원들의 작업 진행 상황 조회

## 운영 탭 하위 메뉴

- **에러 로그** — 로그 분석 및 조회
- **서비스 관리** — 재기동 등 운영 작업
- **버그 트래킹** — 버그 지점 파악 및 추적

## 팀 구조

- 파트 (백엔드, 프론트 등) > 팀원
- 각 팀원은 하나의 파트에 소속
- 팀원의 업무가 파트 단위로 집계

## 기술 스택

- Electron + Vite + React + TypeScript
- 순수 CSS (다크 테마)
- 1차: 목업 데이터, 백엔드 없음

## 1차 범위

1. 3-컬럼 레이아웃 (카테고리 바 / 서브메뉴 / 메인)
2. 개인 · 운영 카테고리 전환
3. 각 하위 메뉴 선택 시 placeholder 화면
4. 슬랙 스타일 다크 테마

## 향후 계획

- AI 도구 (코드 리뷰어, 회의록 요약기, 문서 Q&A 봇, 로그 분석기, API 문서 자동 생성, DB 쿼리 생성기 등)
- 금융/블록체인 도구 (온체인 이상 탐지, 스마트 컨트랙트 감사, DeFi 포트폴리오 어드바이저)
- 백엔드 연동 및 실제 데이터
